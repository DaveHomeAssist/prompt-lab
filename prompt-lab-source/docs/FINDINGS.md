# Prompt Lab FINDINGS: www→apex redirect and HSTS preload (2026-11-22)

**Redirect shipped in PR (branch labbot/www-apex-redirect-2026-11-22):** `vercel.json` `redirects`: host `www.promptlab.tools`, source `/((?!legacy-library-bridge\.html$).*)` → `https://promptlab.tools/$1`, `permanent: true` (path and query preserved). The www bridge page is deliberately left out so the apex can still frame it and read www's localStorage. The tawny migration source (S-24: recovers nothing in Chrome) and its `frame-src` entry are removed; `frame-src` is now `'self' https://challenges.cloudflare.com https://www.promptlab.tools`.

**HSTS preload: conclusion = still NO (keep D-5).** Checked 2026-11-22:
- Live apex and www send `strict-transport-security: max-age=63072000; includeSubDomains`. hstspreload.org's only error for promptlab.tools is `header.preloadable.preload.missing` (no other errors or warnings). So technically one directive away.
- includeSubDomains reaches every subdomain. Known ones: `www` (Vercel; becomes a redirect), `clerk` (Cloudflare, HSTS max-age=63072000, HTTPS fine), `accounts` (Clerk, HTTPS), `mobile` (retired, no DNS). I could not enumerate all of them: crt.sh returned nothing and I have no DNS access to the zone. Any forgotten or future http-only subdomain (mail, status, a staging host) would break for browsers with no way to opt out.
- The www redirect response is a Vercel redirect, which does not get the `headers` rules (R-39), so it carries Vercel's default HSTS. That only governs the www host and is covered by the apex's includeSubDomains once preloaded, so it is not a blocker, but it is one more thing to verify live.
- Domain expiry is Mar 14 2027 (about 112 days). Preload lists are baked into browser releases and removal takes months. If the domain lapsed, was lost, or moved to another owner, every browser would still force HTTPS on it for months.
- Benefit is small: it only protects a first-ever visit over plain HTTP, and the app is a hosted tool plus an extension that does not depend on it.
- Revisit only after (1) the domain is renewed for several years, (2) a full subdomain list is confirmed from the DNS zone, and (3) the live www redirect has been seen to behave. Then add `; preload` and submit. The test in `tests/vercel-headers.test.mjs` still asserts there is no `preload` string so it can't ship by accident.
