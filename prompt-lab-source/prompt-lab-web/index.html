Questions

Know what happens before you open the app.

Do I need an account?

The hosted web app currently asks you to sign in. This landing-page sample does not, and it never sends example content to a provider.

Are AI provider costs included in Pro?

No. Provider usage is separate from Prompt Lab Pro and remains subject to the provider account or local model you choose.

Where are my prompts stored?

The web editor keeps prompts and libraries in local browser storage. A provider receives content only when you intentionally connect it and run a provider-backed action.

Where are provider API keys stored?

Configured keys stay in browser or extension storage. Hosted web requests pass through Prompt Lab's domain-allowlisted proxy for browser compatibility, but the keys are not persisted server-side.

How do I cancel Pro?

Use Manage Billing in Prompt Lab to open Stripe's customer portal, where you can manage or cancel the subscription.

Will choosing Pro charge me immediately?

No. The pricing choice opens Prompt Lab with your monthly or annual preference. You still review and confirm the billing flow inside the app.

Is there a desktop installer?

The repository includes desktop source and build notes. This page does not claim a packaged installer; use the web app unless you specifically want to build the desktop surface.
