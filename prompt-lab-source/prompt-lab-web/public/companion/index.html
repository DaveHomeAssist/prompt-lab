    Offer truth

  2. 02

    Stripe production

    Configure products and secrets

    Activate payouts, create the exact monthly and annual prices, store production identifiers securely, and keep test and live credentials separate.

    Identity and checkout

    Preserve one customer journey

    Require sign-in, bind Stripe customers to stable Clerk user IDs, retain the selected plan through authentication, and prevent duplicate checkouts.

  4. 04

    Lifecycle

    Handle every subscription state

    Verify signed, idempotent webhooks for purchase, renewal, cancellation, payment failure, refund, and deletion. Entitlements must update without a sign-out.

    Pass monthly and annual test purchases, restore green CI, verify the customer portal, then run one explicitly approved live transaction and refund.
