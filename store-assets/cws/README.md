# Chrome Web Store listing assets

Generated by `prompt-lab-extension/e2e/cws-store-assets.spec.js` from the
packaged submission build, driven headlessly with no API key or network. The
current screenshots come from the v1.8.0 release-identity build
(`prompt-lab-v1.8.0-cws.zip`, header label `v1.8.0 (0a5fdd8)`), in the Free
state a new install sees. Regenerate:

```
cd prompt-lab-source/prompt-lab-extension
PROMPTLAB_RELEASE_TAG=v<version> npm run build:cws
CWS_BUILD_DIR=dist-cws npx playwright test e2e/cws-store-assets.spec.js
```

Without `PROMPTLAB_RELEASE_TAG` the build header reads `v<version>-dev (<sha>)`;
do not upload or screenshot that build. Package `dist-cws/` contents (manifest
at the zip root) for upload.

`https://promptlab.tools/privacy`, and submit.
